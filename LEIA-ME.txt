VIVA CONECTA • SISTEMA BKO v1.5

NOVIDADE PRINCIPAL
O formulário Novo Pedido agora espelha as colunas da planilha BKO: Data da Venda, Mês, Tramitação, Vendedor, Razão Social, CNPJ, Endereço/Instalação, Cidade, Representante, Contato, E-mail, Débito Automático, Quality, Vencimento, Tipo de Cliente, Produto, Tronco, Sub Produto, Sub Item, Delta, Outro, Quantidade, Valor Unitário, Valor Contrato, Simulação, Sistema Vivo, Status do Pedido, Cotação, Nº Pedido, Data de Agendamento, Status de Entrega, Data de Entrega, Observações, Previsão de Comissão, Data de Conclusão e Observações Extras.

IMPORTANTE PARA QUEM JÁ USA A V1.4
1. Suba esta pasta na Vercel.
2. No Supabase, abra SQL Editor.
3. Execute UMA VEZ o arquivo BKO-UPGRADE-v1.5.sql.
4. Atualize o Sistema BKO.

O upgrade apenas adiciona colunas. Não apaga pedidos existentes e não substitui o Dashboard comercial.

REGRAS MANTIDAS
- Consultor continua preenchendo Equipe automaticamente.
- Mês é preenchido pela Data da Venda.
- Vencimento pode seguir as Regras Automáticas.
- Valor do contrato pode ser calculado por Quantidade x Valor Unitário.
- Somente pedido APROVADO é enviado ao Dashboard comercial.
- Produto no Dashboard continua sendo escolhido separadamente para garantir o lançamento na torre correta.

VIVA CONECTA • SISTEMA DE ALIMENTAÇÃO BKO • V1

O QUE ESTA VERSÃO JÁ FAZ
- Login usando os usuários do mesmo Supabase do Dashboard.
- Cadastro e edição de pedidos.
- Busca automática de cliente pela base interna usando CNPJ.
- Razão Social e Gestor preenchidos quando o CNPJ já existe.
- Consultor e Equipe lidos diretamente do Dashboard atual.
- Regras configuráveis de Modalidade -> Vencimento.
- Cálculo Quantidade x Valor Unitário.
- Status do pedido separado do status de entrega.
- O pedido NÃO entra no Dashboard enquanto estiver em análise/andamento.
- Quando o status vira APROVADO, o sistema cria automaticamente o lançamento no Dashboard.
- Proteção contra envio repetido do mesmo pedido.
- Se um pedido já aprovado for editado, o lançamento correspondente no Dashboard também é corrigido.
- Dashboard original continua disponível para lançamentos/edições manuais.

IMPORTANTE
Esta V1 usa o mesmo Supabase do Dashboard Viva Conecta e não zera nem altera metas automaticamente.
Como outubro será iniciado zerado, primeiro use no Dashboard atual a função de iniciar novo período/zerar realizados no momento certo.

INSTALAÇÃO
1) Entre no Supabase usado pelo Dashboard.
2) Abra SQL Editor.
3) Cole TODO o conteúdo de BKO-SETUP.sql e execute.
4) Garanta que os usuários do BKO existam em Authentication > Users.
5) Suba esta pasta em um NOVO repositório GitHub (recomendado) ou novo projeto Vercel.
6) Importe o projeto na Vercel.
7) Abra o endereço gerado e faça login com um usuário do Supabase.

NÃO SUBSTITUA O REPOSITÓRIO DO DASHBOARD COM ESTA PASTA.
O Sistema BKO deve ficar como um projeto separado, conectado ao mesmo Supabase.

FLUXO
Pedido criado -> fica no BKO.
Pedido em análise/andamento -> continua só no BKO.
Pedido reprovado/cancelado -> não entra no Dashboard.
Pedido APROVADO -> entra automaticamente no Dashboard.
